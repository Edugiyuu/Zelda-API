## Como criar um novo ADR

1. Copie o ADR mais recente e use o próximo número (`0004-titulo-curto.md`).
2. Preencha **Contexto**, **Decisão**, **Consequências** e, se houver, **Alternativas consideradas**.
3. Adicione a linha na tabela acima.
